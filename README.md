# オンライン人狼

5〜10人で遊べるブラウザ型オンライン人狼です。

## 役職
- 人狼
- 村人
- 占い師
- 騎士
- 霊媒師（現在は役職表示のみ）

## GitHubで動かす
このフォルダをGitHubリポジトリにそのままアップロードします。

Node.js対応のホスティングサービスで実行してください。

```bash
npm install
npm start
```

ポート番号は環境変数 `PORT` を使います。

## 注意
GitHub Pagesだけではこのゲームのサーバー部分は動きません。
Socket.IOを動かせるNode.jsサーバーが必要です。

## ルール
- 5〜10人
- ルームコードで参加
- 夜：人狼・占い師・騎士が行動
- 昼：全員で投票
- 人狼が0人なら村人陣営の勝利
- 人狼が村人と同数以上になったら人狼陣営の勝利
